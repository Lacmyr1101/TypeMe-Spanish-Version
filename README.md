##TypeMe 

Disponible en: https://typeme-spanish-lacmyr.netlify.app

## Descripción

TypeMe es un pequeño videojuego que diseñe para mejorar las habilidades de mecanografía de los usuarios, donde el objetivo principal ganar la mayor cantidad de puntos pulsando las teclas indicadas por el teclado dentro de la interfaz. Inspirado en uno de los proyectos brindados por Código369.com, se desarrolló principalmente para mejorar mis habilidades FrontEnd y para mi portfolio, y posteriormente lo utilicé a modo de Trabajo Especial de Grado (Tesis) para optar por mi título de ingeniero de computación, solventando la problemática del bajo nivel de mecanografía que los estudiantes de mi universidad presentaban.

NOTA: Disponible únicamente para PCs y Laptops, debido a la naturaleza del proyecto.

## Tecnologías utilizadas

- JavaScript.
- Sass CSS.
- HTML.

## Recomendaciones

- Utilizar una técnica de mecanografía que desee aprender o mejorar.
- Aumentar progresivamente la dificultad del juego conforme se sienta más cómodo utilizando esa técnica.
- Una vez domindada la máxima dificultad, empezar desde la más fácil, pero con una nueva técnica más difícil.
